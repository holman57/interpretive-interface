# Contributing to Interpretive Interface

Thank you for helping improve Interpretive Interface!

## Guidelines
- Follow official Kotlin coding conventions and Android Jetpack Compose architecture patterns (Unidirectional Data Flow).
- Ensure new features handle runtime permissions properly with graceful fallback states.
- Test your changes across various Android versions (API 26 to API 35).

## Getting Started
1. Fork the repo and create a feature branch (`git checkout -b feat/your-feature`).
2. Build and verify using `./gradlew build`.
3. Submit a Pull Request describing your changes.
